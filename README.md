# Parche Dev 2026

Sitio oficial del encuentro Parche Dev 2026, construido solo con HTML semántico.
Reto individual del Módulo 1 · HTML y CSS, RIWI.

Sitio publicado: https://TU-USUARIO.github.io/parche-dev/

## Páginas

- Inicio
- Agenda
- Ponentes
- Inscripción y confirmación
- Código de conducta

## Cómo verlo en tu computador

1. Clona el repositorio.
2. Ábrelo en VS Code.
3. Abre index.html con Live Preview.

## Decisiones que tomé

- Uso de <fieldset> y <legend> para organizar el formulario: Decidí utilizar estas etiquetas para agrupar los campos de inscripción en categorías como «Tus datos» y «Agenda», facilitando la comprensión del formulario y mejorando su accesibilidad
- Decidí utilizar input type="radio" para seleccionar la ciudad de residencia, ya que permite elegir una única opción. Aunque hubiera podido utilizar checkbox para permitir múltiples selecciones, consideré que no era adecuado para este campo, porque el objetivo era identificar una sola ciudad por participante

## Lo que aprendí

- Estructuración semántica de HTML: Aprendí a organizar correctamente el contenido de una página web utilizando etiquetas como <header>, <main>, <section>, <nav> y <footer>, comprendiendo la función de cada una
- Creación y validación de formularios: Aprendí a utilizar diferentes campos de entrada, como input, radio, checkbox y select, así como atributos de validación (required, pattern) para controlar la información ingresada por los usuarios
- Navegación y detección de errores: Fortalecí mis conocimientos sobre rutas relativas, enlaces entre páginas y secciones, además del uso del validador W3C para identificar y corregir errores y advertencias en el código HTML
